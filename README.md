# 🤖 GenAI Q&A Chatbot

An end-to-end Generative AI Q&A chatbot built with **Python, LangChain, Google Gemini, and Streamlit*".

The project demonstrates how to integrate a modern Large Language Model (LLM) into a Python application and build a simple natural-language question-answering system.

---

## 🚀 Features

- Natural-language question answering
- Google Gemini LLM integration
- LangChain-based LLM workflow
- Environment-variable based API key management
- Streamlit-based user interface
- Jupyter notebooks for learning and experimentation

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| LangChain | LLM application framework |
| Google Gemini | Generative AI / LLM |
| Streamlit | Web application interface |
| Jupyter Notebook | Experimentation and learning |
| python-dotenv | Environment variable management |
